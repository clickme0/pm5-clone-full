# PM5 Clone для AVM R-002P

Черновой Android-проект: BLE-клиент под гребной тренажёр AVM R-002P (протокол FitShow)
+ интерфейс, визуально копирующий монитор Concept2 PM5.

## Важно, честно

У FitShow нет единой публичной спецификации — офсеты полей в пакете (время,
дистанция, темп, ватты) в файле `ble/FitShowProtocol.kt` заданы **гипотетически**,
по типичной структуре пакетов у FitShow-совместимых тренажёров. Их почти наверняка
придётся подправить под вашу конкретную прошивку. Для этого в приложении есть
встроенный экран "Сниффер".

## Как собрать

1. Установите Android Studio (последняя стабильная версия, Ladybug/Koala+).
2. File → Open → выберите папку `PM5Clone`.
3. Дождитесь синхронизации Gradle (нужен интернет — скачает Gradle, SDK-компоненты).
4. Подключите Android-телефон по USB (или используйте эмулятор — но BLE на эмуляторе
   не работает, нужен реальный телефон), Run ▶.

## Как откалибровать протокол (первый запуск)

1. Включите тренажёр, откройте приложение, разрешите Bluetooth.
2. "Начать сканирование" → выберите AVM (или его MAC-адрес) в списке.
3. После подключения по умолчанию открыт экран "Сниффер" — начните грести.
4. Смотрите на реальный дисплей тренажёра: засеките время (например, 0:10) и
   дистанцию. В логе сниффера найдите пакет, где на нужной позиции стоит число,
   похожее на 10 (0x0A) — это и есть offset для времени. Аналогично для дистанции,
   темпа гребли и т.д.
5. Впишите правильные числа в `FieldOffsets` (файл `ble/FitShowProtocol.kt`),
   пересоберите — на главном экране должны появиться живые цифры.

## Структура

- `ble/BleManager.kt` — сканирование, подключение, подписка на все
  notify/indicate-характеристики (т.к. точный UUID сервиса AVM неизвестен заранее).
- `ble/FitShowProtocol.kt` — разбор кадров, офсеты полей (требуют калибровки).
- `ble/RowingData.kt` — модель данных тренировки.
- `ui/Pm5Screen.kt` — экран в стиле PM5 (крупное окно /500м + пять малых окон).
- `MainActivity.kt` — разрешения, список устройств, переключение экранов.

## Как собрать через GitHub Actions (полностью с телефона, без Android Studio)

1. Распакуйте архив на телефоне.
2. Установите приложение **GitHub** (или Working Copy/Termux, но проще всего сайт
   github.com в браузере телефона — он неплохо работает и с мобильного).
3. Создайте новый **приватный** репозиторий (например, `pm5-clone`).
4. Залейте в него содержимое папки `PM5Clone` (через веб-интерфейс GitHub можно
   перетаскивать файлы по одному/архивом — удобнее всего через приложение
   **GitHub** для Android: "Add file" → "Upload files"; для большого числа файлов
   проще через компьютер друга/работы один раз, дальше уже всё с телефона).
5. Как только файлы залиты (в частности `.github/workflows/build.yml`), GitHub
   сам запустит сборку — смотрите вкладку **Actions** в репозитории.
6. Через 2–4 минуты сборка "Build APK" станет зелёной. Откройте её → в самом низу
   раздел **Artifacts** → скачайте `PM5Clone-debug-apk.zip` (это будет обычный zip
   с одним apk внутри — распакуйте и установите на телефон, включив
   "Установка из неизвестных источников" для вашего браузера/файлового менеджера).

Если сборка упадёт с ошибкой — откройте лог шага, который покраснел, и пришлите
мне текст ошибки, поправим.


## Если протокол окажется не FitShow, а стандартный FTMS

Если после калибровки ничего не бьётся — возможно, тренажёр на самом деле
транслирует стандартный Bluetooth FTMS Rower Data (характеристика 0x2AD1,
сервис 0x1826). Тогда парсинг сильно проще и надёжнее: структура полностью
задокументирована Bluetooth SIG. Дайте знать — допишу отдельный парсер под FTMS,
это буквально другой файл на замену FitShowProtocol.kt.
